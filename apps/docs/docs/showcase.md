Projects and platforms that run EUDIPLO.

## Deployments

| Deployment                                                     | Description                                                                                       | Use case                                         |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| [EUDI Wallet Playground](https://playground.eudi-wallet.org/)  | Playground of the German EUDI ecosystem for testing wallets and their interoperability             | Wallet testing and interoperability              |
| [EUDI Web Client Demo](https://eudi-web-client.h.aioblak.com/) | Public instance of the EUDIPLO Web Client for issuance and presentation flows                     | Demo and testing                                 |
| [espuni](https://www.espuni.com/)                              | Multi-tenant age verification as a service for online platforms subject to DSA Article 28         | EU age verification blueprint                    |

## Add your project

[Edit this page](https://github.com/openwallet-foundation/eudiplo/edit/main/apps/docs/docs/showcase.md) and open a pull request, or [open an issue](https://github.com/openwallet-foundation/eudiplo/issues/new) with the project or organization name, a URL if public, and one sentence on how you use EUDIPLO. Private deployments can be listed with a description only.
