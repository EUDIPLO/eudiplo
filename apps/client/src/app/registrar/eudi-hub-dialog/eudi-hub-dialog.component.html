Request Access Certificate from the EUDI Hub

Sign in to the EUDI Hub portal, open your browser's developer tools, select a request to api.eudi-hub.gov.de in the Network tab and copy the value of its Authorization header. The token expires after a few minutes. EUDIPLO uses it for this request only and does not store it.
