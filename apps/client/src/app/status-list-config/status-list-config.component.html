Status List Aggregation

Per RFC 9528 Section 9, status list aggregation enables verifiers to pre-fetch all status lists for offline validation. When enabled, each status list JWT includes an aggregation_uri pointing to an endpoint that returns all status list URIs. Without a choice, the global default that the operator of this instance sets with STATUS_ENABLE_AGGREGATION applies.
